# Async Labs Screening — Task T4

**Name:** Srivatsa S

## What I built

A set of 5 high-fidelity homepage sections (plus a mobile adaptation) for the smart e-paper workspace display, designed around a specific persona: a **dual professional** — someone who is both a tech professional and a professional musician (Mridangam artist).

The narrative centers on a single tension: this person's rehearsal schedule, guru's class timings, and concert bookings live in a completely different world from their sprints, meetings, and deadlines — and no existing tool shows both at once. Each section builds on this "two lives, one display" story, moving from problem → customization → integrations → automation → a closing call to action.

## Prototype flow

The CTA button in the final section ("Get Started") is wired back to Section 1, creating a closed loop — clicking through the sections in order brings you back to where the story started.
